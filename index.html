📖 دليل خطوات الإعداد المجاني لربط Google Drive (مرة واحدة فقط)

  1. افتح موقع Google Cloud Console (console.cloud.google.com) وسجّل الدخول بحسابك في Gmail.
  2. اضغط على New Project في الأعلى وأنشئ مشروعاً جديداً (مثلاً باسم: Ophthalmology Logbook).
  3. من القائمة الجانبية اختر APIs & Services > Library، ابحث عن Google Drive API واضغط على Enable (تفعيل).
  4. اذهب إلى OAuth consent screen، اختر External، اكتب اسم التطبيق وبريدك الإلكتروني، وأضف بريدك (أو إيميلات زملائك الأطباء) ضمن قائمة Test users.
  5. اذهب إلى Credentials > Create Credentials > OAuth client ID، واختر نوع التطبيق Web application.
  6. في خانة Authorized JavaScript origins أضف رابط الموقع الذي تستضيف عليه الملف (مثلاً http://localhost أو رابط GitHub Pages / Netlify)، ثم اضغط Create.
  7. انسخ الـ Client ID الظاهر لك والصقه في الحقل أعلاه (وهو مثبت مسبقاً في الكود عند DEFAULT_GOOGLE_CLIENT_ID ليعمل لجميع الأطباء مباشرة).
